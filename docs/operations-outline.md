# 部署与运维方案

> 版本：v0.5 · 状态：本地 MVP 运维草案，待系统工程师评审  
> 日期：2026-09-30

## 1. 当前支持形态

本项目当前支持受信任设备上的本地单用户运行：Python 3.12+、FastAPI/Uvicorn、浏览器静态 UI、SQLite 文件和外部模型 API。当前没有认证、组织权限、高可用、生产数据加密或线上 SLA；不要将端口暴露到公网或作为多用户生产服务使用。

## 2. 本地运行

```sh
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 在本机安全编辑 .env，设置模型提供方所需密钥
uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

浏览器访问 `http://127.0.0.1:8765/`。开发热重载可附加 `--reload`。不要将有效密钥复制进 shell 命令历史、聊天、issue 或浏览器端配置。

## 3. 配置与密钥

- `.env` 仅供后端加载，必须保持在忽略列表内并限制本机文件权限。
- DeepSeek 兼容配置包括 `DEEPSEEK_API_KEY`、可选 `DEEPSEEK_BASE_URL` 和 `DEEPAGENTS_MODEL`。
- 无密钥或缺少 Agent 依赖时，项目状态工作台仍可读取/保存，但 Agent 不应被视为可用。
- 轮换密钥时在受控终端更新本地 `.env` 后重启服务；不要在日志中打印环境变量。

## 4. 持久化和备份

- SQLite 主数据：`.data/zhidian.sqlite3`。WAL 模式可能同时产生 `-wal` 与 `-shm` 文件。
- 服务以单个 Uvicorn worker 运行时才提供当前进程内锁保护；不要启用多 worker 或多个服务进程共同写同一 SQLite/整份 JSON 状态。
- 备份应使用 SQLite 在线备份接口或停服后同时一致地复制数据库文件；不要在服务运行时只拷贝主文件并假设包含全部 WAL 数据。
- 备份应加密、设置访问控制和保留周期，并进行定期恢复演练。
- 文档历史快照保存在同一数据库，不替代独立备份。
- 恢复前停止写入，保留损坏库副本，记录备份版本与恢复结果。

### 数据保留与导出边界

- 项目状态、会话、记忆、事件和文档版本保存在本机 SQLite；应用没有自动到期删除或云端副本，数据持续保留，直到用户显式删除项目或操作者停止服务并删除数据库及其 WAL/SHM 文件。
- 项目选择器提供完整 JSON 导出，包含元数据、当前状态、会话、事件和文档版本快照；文件不包含环境变量/密钥，但目前不能直接导入恢复。
- Markdown 项目包和需求 CSV 用于阅读/交接，不包含全部审计事件及文档版本快照，不替代 JSON 导出或 SQLite 备份。
- 用户可删除非默认项目，需输入完全匹配的项目名称；项目状态、消息、事件和文档历史会永久清理。默认项目受保护。没有回收站、批量清理或自动保留周期。
- SQLite 备份可能含完整项目对话、用户输入、AI 输出和文档；按敏感项目资料管理，不上传到未批准的存储位置。

## 5. 监控与故障处理

- `GET /api/health` 查看应用和 Agent 配置状态；不包含模型密钥。
- 模型调用失败先检查运行依赖、供应商状态、模型名和密钥有效性；密钥不得回显给用户。
- 若文档误改，可从该文档版本历史预览并恢复，恢复操作应生成新版本。
- 若项目数据损坏，停止服务后恢复最近一份经验证的 SQLite 备份；必要时保留当前库供排查。
- 定时会议由应用进程内调度，停机期间不会运行。服务重启时会把遗留的“进行中”会议标为失败、保留已保存发言、清除运行标记并重排下一轮；不会自动续跑中断会话，也没有多实例任务队列。普通逾期的下一轮由 scheduler 启动后按保存时间处理。
- 当前项目动态读取审计事件表；还没有完整的结构化服务日志、指标、告警、链路追踪或模型成本仪表盘。

## 6. 发布、回滚与数据迁移

本地开发升级前备份 `.data/zhidian.sqlite3`，审阅代码变更和数据结构影响；升级后确认 `/api/health`、项目列表、文档正文和版本 API 可用。若失败，停止服务、保留故障库并回到前一代码版本；数据迁移需由对应变更提供兼容/回滚说明。当前服务启动会对既有项目文档建立迁移基线快照。

## 7. 生产化前置工作

增加用户认证、组织权限和请求校验；部署平台密钥管理；数据库备份/恢复演练及 JSON 导入恢复；多人并发写入控制；任务队列和会议故障恢复；结构化日志/监控/告警；速率限制和外部服务评估；企业级隐私、保留和删除审计策略；负载、恢复时间和可用性目标。

## 8. 当前数据操作的用户可见边界

项目选择器可下载 JSON 完整数据导出，也可对非默认项目输入全名后删除；默认项目不能在 UI 删除。JSON 导出当前不能导入恢复；需要完整恢复请使用 SQLite 备份。没有自动删除周期，具体保留期限由操作者自行管理。
